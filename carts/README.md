# carts/

Демо-картриджи консоли. Каждый картридж — папка с `src/*.cs` и ассетами,
упаковывается CLI-командой `quarp pack` в один файл `.quarp8`.

**Быстрый запуск без терминала** — батники в [`play/`](../play/): двойной клик
по `play/platformer.cmd` (или любому другому) открывает игру на единственном
разрешении консоли — 160×90 (ADR-021).

| Картридж | Жанр | Зачем он здесь |
|---|---|---|
| `snake` | змейка | первый картридж (M1); **носитель якорей детерминизма** — его хэши и эталонный реплей проверяет CI, менять без переприпина голденов нельзя |
| `platformer` | вертикальный платформер «Tower Climb» | обязательный «худший случай» №1 вердикта по разрешению (M4): вертикальный обзор |
| `dialogue` | диалоговая сцена «Two Lights» | обязательный «худший случай» №2: плотность текста при шрифте 4×6 |
| `breakout` | брейкаут | безопасный жанр; Fix-математика отскоков |
| `digger` | копатель | карта из `map.csv` больше экрана, `Mset`, следящая камера |
| `shmup` | вертикальный шмап | пулы объектов, волны, детерминированный `Rnd` |

Пять демо написаны на этапе 3 вехи M4 как доказательная база решения
«128×72 против 160×90» (приказ: `docs/milestones/M4-WORKORDER.md`, метрики —
`docs/milestones/M4-MEASUREMENTS.md`; вердикт — 160×90, ADR-021, после чего
консоль переехала целиком и спайк-профиль удалён). Все шесть картриджей читают
размеры экрана из API и запускаются одинаково: `quarp run carts/<имя>`.

У каждого демо в `replays/` лежит `walkthrough.input` — скриптованное прохождение
до конечного состояния игры (грамматика — в шапке файла); записанные `.qrpr` в
репозиторий не кладутся, кроме эталонного `snake/replays/golden.qrpr`.
