# snake

Классическая «змейка» — первый демо-картридж QUARP-8: поле 16×8, ускорение с каждым яблоком, рекорд сохраняется между запусками.
Запуск: `quarp run carts/snake`

## Звук (M3)

| Файл | Что это |
|---|---|
| `sfx.txt`, `music.txt` | авторский текст — то, что правят руками ([AUDIO-FORMAT.md](../../docs/AUDIO-FORMAT.md) §6) |
| `sfx.bin`, `music.bin` | собранные банки; **генерируются, но лежат в репозитории** — иначе `.quarp8` не собрать без тулинга |

Слоты: `0` — писк на яблоко, `1` — шум смерти, `2`–`5` — два голоса фоновой темы.
Тема идёт по каналам 2 и 3, каналы 0 и 1 оставлены свободными нарочно: `Sfx()` берёт
младший свободный канал, поэтому писк никогда не перебивает музыку.

После правки текста:

```
quarp audio build carts/snake          # пересобрать банки
quarp audio build carts/snake --check  # то, что делает CI: собрать и сравнить, ничего не записывая
```

Изменение звука меняет идентификатор картриджа (REPLAY-FORMAT §5), поэтому за ним следует
перезапись `replays/golden.qrpr` — команда в `replays/README.md`. Хэши кадров при этом
меняться не обязаны и в M3 не изменились: `Sfx`/`Music` не трогают ничего, что видит
растеризатор.
