# play/ — запуск игр двойным кликом

Один файл — одна игра, на единственном разрешении консоли (160×90, ADR-021). Батники
`*-160x90.cmd`, которыми во время спайк-вердикта M4 запускался `--profile 8w`, удалены —
профиль-флаг ушёл из CLI вместе со спайком, а базовый батник каждой игры сам стал
160×90.

Клавиши в окне: стрелки/Z/X — игра, Space — пауза, `.` — шаг, `,` — шаг назад,
`[` `]` — скорость, Backspace — перемотка, Esc — выход.

Нужен ярлык на рабочем столе — правый клик по батнику → «Отправить → Рабочий
стол (создать ярлык)». Файлы используют относительные пути и при отсутствии
сборки собирают её сами.
