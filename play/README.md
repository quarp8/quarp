# play/ — запуск двойным кликом

## Что чем запускать

| Файл | Что делает |
|---|---|
| **`quarp.cmd`** | **консоль целиком**: меню → библиотека → игра ↔ редакторы. Отсюда и только отсюда доступны редакторы |
| `snake.cmd`, `breakout.cmd`, `digger.cmd`, `platformer.cmd`, `shmup.cmd`, `dialogue.cmd` | одна игра сразу в игру, минуя меню |
| `Quarp.lnk` | ярлык на собранный `quarp.exe` — то же, что `quarp.cmd`, но без чёрного окна консоли позади |

Одиночные батники передают путь к картриджу — это **прямой запуск**, и редакторы в нём
недоступны (клавиши вкладок там не работают). Хотите править игру — запускайте `quarp.cmd`.

Ярлык `Quarp.lnk` в репозиторий не входит (`.gitignore`): он двоичный и хранит абсолютный
путь этой машины. Пересоздать его на другой машине — правый клик по `quarp.cmd` →
«Отправить → Рабочий стол (создать ярлык)», либо указать ярлыку `quarp.exe` и поставить
«Рабочая папка» = корень репозитория. Сами батники используют относительные пути и при
отсутствии сборки собирают её сами.

## Клавиши в окне

Игра: стрелки, `Z`, `X`.

Время: `Space` — пауза, `.` — шаг вперёд, `,` — шаг назад, `[` `]` — скорость,
`Backspace` — перемотка назад.

**`Esc` в игре больше не выход, а меню паузы поверх кадра** (M9 этап 5, ADR-042). На паузе
сверху появляется полоса — стрелка выхода, имя игры, вкладки, — а в середине экрана три
строки:

```
 RESUME          ESC
>STEP <    93    >
 EXIT
```

Стоя на строке `STEP`, `←` и `→` мотают время. **Зажатая стрелка разгоняется**: чем дольше
держите, тем крупнее шаг, так что за несколько секунд можно уехать в начало сессии.
По стрелкам можно и кликать.

Вкладки (после `Esc`, то есть при поднятом меню): `F1` игра, `F2` код, `F3` спрайты,
`F4` карта, `F5` звуки, `F6` музыка; `Alt`+стрелки — по кругу. `Ctrl+S` сохраняет, и игра
продолжается **с того же тика** с новыми кодом или данными — ради этого и делался
детерминизм.

Разрешение одно — 160×90 (ADR-021). Батники `*-160x90.cmd`, которыми во время
спайк-вердикта M4 запускался `--profile 8w`, удалены вместе с профиль-флагом.
