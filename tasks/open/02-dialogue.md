# Диалоговая сцена (обязательный худший случай №2)

Сцена на двоих: портреты 16×16 (спрайты через `Sset`), имя говорящего, окно текста
в три строки, листание `Btnp`, минимум одна развилка выбора игрока, две концовки.
Суммарный текст — не меньше трёх обменов по ~40 слов (worst case по тексту).
Шрифт системный 4×6 (глиф 3×5+1). Звук: ≥2 sfx (лист, выбор) + фоновая тема.
Раскладка окна — только от `ScreenWidth`/`ScreenHeight`.

Критерии (наблюдаемым поведением):
- с `walkthrough.input` сцена дочитывается до одной из концовок; второй сценарий
  или ветка показывает, что выбор меняет исход (разные финальные хэши двух прогонов
  с разными выборами);
- портрет 16×16 + имя + три строки текста помещаются в окно одновременно;
- аудио-хэш сима 600 тиков ≠ digest тишины.

В отчёт — числа Р7: доля экрана под окном из трёх строк; символов в окне; окон на
обмен репликами в 40 слов; влез ли портрет с именем; строк поля после HUD.

Non-goals: не трогать ничего вне carts/dialogue/**; реплики ради метрики не сокращать
(Р19); общий код с другими демо не заводить (Р18); движок не править — дыры API
возвращать находками (Р15); `dotnet build/test/run` не запускать (Р17).
