# Брейкаут-лайк

Ракетка, мяч на `Fix`-математике (углы через `SMath`), поле кирпичей, жизни, счёт,
HUD. Победа — очищенное поле; проигрыш — жизни кончились. Спрайты — `Sset` или
примитивы. Звук: ≥2 sfx (отскок, разбитый кирпич) + фоновая тема. Раскладка поля —
только от `ScreenWidth`/`ScreenHeight`.

Критерии (наблюдаемым поведением):
- с `walkthrough.input` сносится хотя бы один ряд кирпичей и теряется хотя бы одна
  жизнь без исключений; хэш прохождения ≠ хэшу холостого сима (Р20);
- мяч не покидает пределы экрана ни на одном тике прохождения;
- аудио-хэш сима 600 тиков ≠ digest тишины.

В отчёт — числа Р7: строк поля после HUD; рядов кирпичей и запас по высоте между
нижним рядом и ракеткой в тиках полёта мяча.

Non-goals: не трогать ничего вне carts/breakout/**; общий код с другими демо
не заводить (Р18); движок не править — дыры API возвращать находками (Р15);
`dotnet build/test/run` не запускать (Р17).
