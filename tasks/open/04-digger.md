# Копатель

Сеточный копатель в духе Boulder Dash: уровень — настоящая карта `map.csv` →
`quarp map build` (Р16), копание — `Mset`, самоцветы, падающие валуны (давят),
выход открывается после сбора N самоцветов. Камера следит за игроком по карте
больше экрана. Спрайты — `Sset`. Звук: ≥2 sfx (копание, самоцвет) + фоновая тема.
Раскладка и камера — только от `ScreenWidth`/`ScreenHeight`.

Критерии (наблюдаемым поведением):
- с `walkthrough.input` уровень проходится до выхода: собраны самоцветы, выход
  открыт, игрок в нём — без исключений; хэш прохождения ≠ хэшу холостого сима (Р20);
- выкопанная клетка остаётся пустой (`Mget` меняется), валун, лишённый опоры, падает;
- аудио-хэш сима 600 тиков ≠ digest тишины.

В отчёт — числа Р7: строк поля после HUD; видимая доля уровня на экране; хватает ли
обзора, чтобы увидеть валун над собой до того, как он упал (в тиках).

Non-goals: не трогать ничего вне carts/digger/**; общий код с другими демо
не заводить (Р18); движок не править — дыры API возвращать находками (Р15);
`dotnet build/test/run` не запускать (Р17).
