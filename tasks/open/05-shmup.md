# Шмап

Вертикальный шмап: корабль игрока внизу, волны врагов сверху, пули обеих сторон,
жизни, счёт, HUD. Победа — пережить все волны (или босса); проигрыш — жизни
кончились. Спрайты — `Sset`. Звук: ≥2 sfx (выстрел, взрыв) + фоновая тема.
Раскладка — только от `ScreenWidth`/`ScreenHeight`.

Критерии (наблюдаемым поведением):
- с `walkthrough.input` сбивается не меньше одной волны и доигрывается до конца
  (победа или смерть) без исключений; хэш прохождения ≠ хэшу холостого сима (Р20);
- одновременно живут ≥8 пуль и ≥4 врага хотя бы на одном тике (нагрузка, а не слайд-шоу);
- аудио-хэш сима 600 тиков ≠ digest тишины.

В отчёт — числа Р7: строк поля после HUD; тиков от появления вражеской пули на краю
до игрока на типичной скорости (окно уклонения).

Non-goals: не трогать ничего вне carts/shmup/**; общий код с другими демо
не заводить (Р18); движок не править — дыры API возвращать находками (Р15);
`dotnet build/test/run` не запускать (Р17).
