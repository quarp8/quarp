# Сводка чисел Р7 по шести играм

Консолидировать метрики Р7 приказа в одну таблицу-доказательство для вердикта
этапа 4: платформер (окно реакции в тиках, высота прыжка, камера), диалог (доля
экрана, символы, окна на 40 слов, портрет), общие (строки поля после HUD во всех
шести играх, включая змейку — read-only). Числа бригад НЕ переписывать на веру:
каждое перевыводится из констант кода игры или подсчёта; спорные — живым прогоном
`--break-at`/паузой. Расхождение с отчётом бригады — строкой в раздел «Расхождения»,
а не молчаливой правкой.

Критерии (наблюдаемым поведением):
- каждое число в таблице снабжено выводом (константа кода → арифметика → число),
  а не ссылкой на отчёт;
- порог Р7 «окно реакции ≥15 тиков» сопоставлен с фактом явно: прошёл/не прошёл;
- для змейки — только подсчёт строк HUD, ни одной правки в carts/snake/**.

Non-goals: carts/** не править вовсе (read-only зона); вердикт не выносить —
таблица приносит числа, решает владелец на этапе 4 (ADR-005); новых инструментов
не заводить (Р19).

Зависимость: раздаётся после интеграции пяти демо.
