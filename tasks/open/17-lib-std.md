# Quarp.Api.Std — библиотека v1 по Р27/Р28/Р30

Состав (каждый метод — со ссылками на вхождения из таблицы оракула 4.1 в докстринге):
PrintInt/IntWidth (обобщить диапазоны: digger 0–99, shmup 0–9999 — общий цикл);
PrintCentered/PrintRight; PaintPattern ('.'=пропуск, hex=запись включая 0);
Clamp/Min/Max для int и Fix. Рисующие — расширениями IConsoleApi, чистые — статикой.

Критерии (наблюдаемым поведением): картридж-стенд в тестах печатает счёт через
Q.PrintInt и рисует спрайт через Q.PaintPattern — кадр совпадает с эталоном,
собранным старым локальным кодом (доказательство эквивалентности форм);
QRP1004 краснеет на PaintPattern из Draw; контрактный тест чистоты краснеет
на нарочном float (вернуть по sha256); лимит кода стенда не изменился от
использования Std (CodeBudget меряет только исходники картриджа).

Non-goals: AABB не включать (Р28 — под порогом); SMath и прочее железо не трогать;
carts/** не трогать (конверсия — волна 2); Cartridge не растить методами.
