# Конверсия пяти демо на Std — поведенчески нейтральная (Р29)

Заменить локальные копии (все вхождения — таблица оракула 4.1) вызовами Std;
данные спрайтов привести к каноническому диалекту ТАК, чтобы записи в лист были
байт-в-байт прежними (shmup: маска '#'+цвет → hex-строки той же раскладки;
digger: явные нули остаются '0'; пропуски — '.').

ГЛАВНЫЙ ИНВАРИАНТ: кадровые И звуковые хэши всех прогонов каждого демо
(idle + walkthrough, длины из README) обязаны совпасть с доконверсионными
байт-в-байт. Разошёлся хоть один — конверсия этого демо откатывается и
разбирается, не «перезамеряется».

Критерии: диф каждого демо — минус локальные хелперы (PrintInt/Digits/IntWidth,
центрирование, клампы, парсеры спрайтов), плюс вызовы Std; хэш-таблица
до/после в отчёте — все равны; негативный контроль — порча одного пикселя
в данных спрайта двигает кадровый хэш (вернуть); попутно снять комментарии
про удалённый спайк в этих пяти файлах (debt-move-cleanup п.2 — identity
всё равно сдвигается этой конверсией, момент правильный).

Non-goals: змейку не трогать; геймплей/константы/тексты не менять; README —
только абзацы про хелперы и отметку о конверсии; треки .input не трогать
(они обязаны остаться валидными по построению).
