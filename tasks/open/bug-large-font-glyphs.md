# Крупный шрифт v1 забракован глазами владельца

Плейтест (2026-08-18): «стало хуже, чем было — сильно больше букв плохо
читаются». Витрина (проза диалога крупным) откачена: carts/dialogue вернулся
на мелкий шрифт (состояние 704cfae). API Font.Large, рендер, тесты и
перегрузка Print ОСТАЮТСЯ — бракованы только пиксели глифов v1.

Урок (третий подряд): глифы, которых не видел человек, не выпускаются
в игру. Бригада v1 рисовала вслепую и сама называла спорные (e, a, X, w, 9)
— владелец подтвердил худший исход. Доработка БЛОКИРОВАНА на цикл визуальной
приёмки: либо quarp sim --dump-frame (idea-cart-debug-channel — уже ТРИ
эпизода, где он был нужен), либо стенд-картридж с алфавитом + скриншоты
владельцу до какого-либо использования шрифта в демо.

Порядок: не раньше этапа 4, вместе с вердиктом (если 128×72 — приоритет
крупного падает сам собой; если 160×90 — рисовать v2 с алфавитным стендом
и итерациями по скриншотам владельца).

Критерий: владелец читает алфавитный стенд крупным шрифтом и говорит
«лучше мелкого», а не «хуже»; до этого Font.Large не используется ни в
одном картридже репозитория.

Non-goals: перегрузку Print, enum Font, метрики 5×7 не трогать (решение
владельца о двух шрифтах в силе); мелкий 3×5 не трогать; API-8 §3 не
откатывать (там правда о коде).
