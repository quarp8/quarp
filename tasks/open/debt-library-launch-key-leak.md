# Зажатая Z/Enter из библиотеки протекает в первый кадр игры

Находка бригады волны 1 этапа 1 M9 (сдана в разделе «в чём не уверена», в карточки
волны не входила): запуск картриджа из библиотеки происходит по нажатию Z/Enter,
и если палец ещё на кнопке, картридж на первом кадре видит O/Start нажатыми —
InputMapper честно читает уровень (и не должен edge-детектить: это контракт кнопок
игры). Обратное протекание (Esc/стрелки из игры в библиотеку) устранено единым
ридером ещё в волне 1.

Решить: подавить кнопку запуска до её первого ОТПУСКАНИЯ после перехода
Библиотека→Игра (ворота в оболочке, не в InputMapper — контракт API не трогается).
Негативный контроль: без ворот картридж-зонд видит O на тике 0, с воротами — нет.

Non-goals: InputMapper и семантику Btn/Btnp в API не менять; детерминизм не трогать
(ворота живут до симуляции — во входном слое оболочки, реплеи пишут уже
отфильтрованный вход, как и любой другой ввод).
