# «Карта руками в тексте» не работает для настоящего уровня

Находка бригады G (этап 3): формат требует ровно 72 строки по 256 значений
независимо от размера уровня. Пещера 40×24 — это 18 432 числа, 38 КБ текста,
94 % нулей; руками такое не пишут и глазами не проверяют. G разворачивала карту
скриптом из ASCII-эскиза. MAP-FORMAT §5 честно отвечает «рисуйте в Tiled», но §4
продаёт ручной путь как рабочий.

Независимое подтверждение бригадой P: башня шириной 24 тайла → 90.6 % клеток
файла лежат в столбцах, куда игра не дотягивается; пришлось заводить генератор
(carts/platformer/tools/tower.py). Предложение P: `# width N` в шапке — компилятор
принимает усечённую геометрию, остальное пусто. Два независимых генератора
за один этап — это уже не неудобство, а отсутствующий инструмент.

Решить (не раньше конца этапа 3, документная правка — можно до ратификации):
минимум — §4 говорит вслух «ручной путь — для точечных правок, настоящий уровень —
Tiled»; максимум — компилятор принимает усечённую геометрию (меньше строк/значений =
остальное пусто) через ADR, помня решение Р11 «неполная строка не добивается нулями»
(оно про опечатки внутри строки — противоречие надо разрешить явно).

Критерий: автор с README делает уровень 40×24, не написав ни одного скрипта.

Non-goals: бинарный формат map.bin не трогать; якоря не двигать.
