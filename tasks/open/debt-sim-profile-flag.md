# Headless-проверки раскладки на другом профиле нет

Две независимые бригады этапа 3 (G, S) упёрлись в одно: `--profile` есть только
у `quarp run` (окно), поэтому раскладку на 160×90 нельзя проверить ни симом,
ни реплеем — только расчётом и глазами владельца. Для этапа 3 это осознанное
решение (Р19), но в M6 приходит Profile16 — и «одна сборка, два профиля»
станет постоянной реальностью, а headless-канала под неё нет.

Решить ПОСЛЕ вердикта по разрешению (этап 4): если спайк 8w умирает — карточка
переоценивается под M6 (sim --profile для Profile16-разработки); если 8w
становится спекой — инструмент нужен сразу для переприпина.

Критерий: `quarp sim <cart> --profile <p> --ticks N` печатает хэш кадра этого
профиля; голдены Profile8 неподвижны (негативный контроль: без флага хэши
прежние).

Non-goals: до вердикта не реализовывать (Р19); в CI не вносить (Р6).
