# У слота 15 «тёмный двойник» светлее оригинала

Находка бригады V (этап 3): затемнение сцены делается через Pal на «тёмных
двойников» слотов, но таблицы «слот → тёмный двойник» нет ни в SPEC-8 §2,
ни в API-8, автор строит её на глаз по hex-черновику. При этом у слота 15
(светлая кожа) двойник 31 СВЕТЛЕЕ оригинала — ловушка без предупреждения.

Учесть при финализации hex палитры (этап 4, ADR-016): либо выправить яркостную
монотонность пар при подборе финальных значений, либо честно задокументировать
таблицу пар с оговоркой, где она ломается. Затемнение через Pal — приём,
который повторит каждая игра с «отошёл в тень».

Критерий: автор затемняет любой слот по документированной таблице и не получает
осветления.

Non-goals: не менять hex-черновик до этапа 4; не изобретать новый API затемнения.
