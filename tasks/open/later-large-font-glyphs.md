# Крупный шрифт v2 — ОТЛОЖЕНО ВЛАДЕЛЬЦЕМ до после релиза

v1 забракован глазами владельца (2026-08-18): «сильно больше букв плохо
читаются». Витрина откачена; API Font.Large, рендер, перегрузка Print,
тесты и голден textlarge остаются в дереве, глифы v1 не используются
ни одним картриджем. Владелец: «шрифтами займёмся после релиза».

ХВОСТ ГРИЛЯ ЗАКРЫТ (2026-08-19, ADR-024): владелец ратифицировал сигнатуру
и метрики Font.Large; глифы — качество реализации, v2 правится без ADR.
Осталась только сама работа v2 — после релиза, через визуальную приёмку.

Правило v2 (урок, купленный дважды 2026-08-18): ни один глиф не едет
в игру мимо глаза владельца; итерации — через алфавитный стенд или
quarp sim --dump-frame (idea-cart-debug-channel); ASCII-арт не приёмка.

Критерий: владелец читает алфавитный стенд крупным и говорит «лучше
мелкого»; до этого Font.Large не используется в carts/**.

Non-goals: перегрузку/enum/метрики не трогать; мелкий 3×5 не трогать.

ДОПОЛНЕНО (2026-08-31, ADR-038): в мелком шрифте появился блок из 32
глифов PICO-8 (стрелки, кнопки, ♥ и пр.) — это отдельное решение по
заказам портов, не работа этой карточки, и мелкий ASCII 3×5 оно не
трогает. Крупный шрифт символы блока СОЗНАТЕЛЬНО не получил: рисует
свою болванку (тест TheLargeFontDrawsItsFallbackForSymbols). К объёму
v2 этим добавились 32 глифа блока — рисовать их тем же порядком, через
визуальную приёмку владельца, вместе с буквами. Зона карточки прежняя.
