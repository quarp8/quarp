# Повторы, наблюдённые в демо — сырьё для библиотеки (Р10)

Правило: в библиотеку попадает то, что фактически повторилось ≥3 раз из шести демо.
Здесь копятся наблюдения из отчётов бригад с указанием зон. НЕ реализовывать
до этапа 4.

| Кандидат | Где наблюдён | Счёт |
|---|---|---|
| PrintInt/Digits (печать целого без аллокаций) | snake, breakout, shmup, digger, platformer (дословно из змейки) | **5 — порог** |
| Спрайты из текста/кода (hex/ASCII-паттерн → Sset) | shmup, digger, dialogue, platformer | **4 — порог** |
| Центрирование текста `(W − len*4)/2` | snake, breakout ×3, dialogue ×2, platformer ×3 (+вправо ×2) | **4 — порог** |
| Клампы руками (System.Math забанен; Fix и int) | breakout ×2, shmup, digger | **3 — порог** |
| Следящая камера (зажим к миру, сглаживание/упреждение) | digger, platformer | 2 |
| AABB Overlaps(...) | breakout (3 формы), shmup | 2 |
| Шаговый таймер + защёлка направления | snake, digger (один в один) | 2 |
| Перенос текста по словам (+страницы, +печать по буквам) | dialogue (~45 строк; кандидат №1 по весу) | 1 |
| Тайловый контроллер персонажа (бокс против карты, one-way, coyote, буфер прыжка) | platformer (~120 строк) | 1 |
| Снимок карты для рестарта (Mset разрушителен) | digger (~20 строк) | 1 |
| Меню (курсор, зажим, подтверждение) | dialogue (~20 строк) | 1 |
| MinInt/MaxInt | breakout | 1 |
| Пул объектов на параллельных массивах | shmup (3 копии в одном файле) | 1 |

Смежные дыры API (не библиотека), решать вместе с библиотекой на этапе 4:
- нет `Print(char)` и печати подстроки без аллокации — dialogue строила
  таблицу из 95 односимвольных строк в Init ради печати по буквам;
- нет способа спросить у консоли метрики шрифта (advance/межстрочье) —
  после появления Font.Large каждый картридж дублирует пары 4/6 и 5/7
  константами (находка бригады 08: вторая копия факта движка).

Критерий: к началу этапа 4 у каждой строки — точные ссылки файл:строка по всем
зонам, счёт ≥3 → кандидат в карточку библиотеки, счёт <3 → отклонён с записью.

Смежное: семейство коллизий (AABB, бокс-против-карты, tile-контроллер) выделено
в idea-collision-helpers.md — владелец принёс рыночный сигнал (жалобы авторов
PICO-8 на ручные коллизии), который поднимает приоритет этих строк таблицы.

Non-goals: не заводить общий код на этапе 3 (Р18); не чинить демо ради красоты
списка.
